# Birdsong Visualizer 🌌🐦
### *A Lens into the Invisible.*

Birdsong Visualizer is a professional-grade spectral analyzer turning birdsong acoustics into fluid particle visualizations.

## 🚀 Key Features

* **Surgical Audio Isolation**: Pre-Amp dynamics compressor and spectral noise gate to profile signals.
* **High-Fidelity Rendering**: OpenGL-accelerated particle system mapping real-time frequency ripples.
* **Native Bridges**: Built with Capacitor to run smoothly on Android and iOS hardware.

## 🛠️ Setup & Running

**Prerequisites:** Node.js

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Launch Application**:
   ```bash
   npm run dev
   ```
